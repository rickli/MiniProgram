# Specification: Diary Frontispiece Detail Page (个人日记扉页式详情页)

## 1. 视觉愿景 (Visual Vision)
将枯燥的打卡记录页重塑为具有仪式感的“个人日记扉页”。设计重心从“填表”转向“记录时刻”，强调情感表达、呼吸感和纸质书写的视觉美感。

## 2. 核心布局架构 (Layout Architecture)
- **页面背景 (Page Background)**: 采用极简的浅灰蓝色 (`#f4f5f7`)，消除视觉压力。
- **沉浸式卡片 (Immersive Card)**: 
  - 页面中央为一个整体的白色大卡片，边距左右各 `30rpx`。
  - **圆角 (Radius)**: `28rpx` 大圆角，营造柔和感。
  - **投影 (Shadow)**: 极其微弱的弥散阴影 (`rgba(0,0,0,0.06)`)，产生轻盈浮动的视觉效果。

## 3. 详细设计模块 (Detailed Module Design)

### 3.1 叙事顶栏 (Narrative Header)
- **背景 (Background)**: 渐变色背景从微信绿向天空蓝过渡 (`linear-gradient(135deg, #07c160, #00b0ff)`)。
- **时间展示 (Time)**: 采用大号、加粗字体，格式为 `2026.03.27 21:40`。
- **地理位置 (Location)**: 紧贴时间下方，配合微缩定位图标 📍，文字色值调低透明度，呈现轻盈感。

### 3.2 心情选择器 (Mood Selector)
- **排版 (Layout)**: 5 个 Emoji 水平平铺，居中对齐。
- **底座 (Base)**: 每个图标带有 `44x44px` 的浅灰色圆角矩形背景 (`#f8f9fb`)。
- **选中态 (Active)**: 选中项缩放 `1.15` 倍，背景变为亮绿色 (`#07c160`)，并带有绿色微光投影。

### 3.3 纸感手记区 (Note Area)
- **设计细节**: 输入框左侧带有一条 `3rpx` 宽的浅灰色引导线 (`border-left`)。
- **排版 (Typography)**: 行高设定为 `1.8` 倍，模拟格纹纸间距。
- **字体样式 (Style)**: 提示文字和内容采用略微倾斜或极细字体，颜色使用深灰 (`#666`)。

### 3.4 影像影集 (Photo Gallery)
- **形态 (Shape)**: 采用拍立得风格的圆角白框 (`12rpx` radius)。
- **添加按钮 (Add Button)**: 采用灰色虚线框，内部为极简的细线加号。

### 3.5 随手标签 (Pill Tags)
- **样式 (Style)**: 胶囊型 (`Pill`) 标签，低饱和度配色。
- **色值 (Colors)**: 背景 `#e1f5fe`，文字 `#0288d1` (莫兰迪蓝)。

### 3.6 珍藏操作 (Save Action)
- **形态 (Shape)**: 底部悬浮的胶囊按钮 (Floating Pill Button)。
- **动效 (Glow)**: 按钮下方带有半透明的绿色弥散投影。
- **文案 (Copy)**: 由“保存记录”改为 **“珍藏这一页”**。

## 4. 技术实现要点 (Implementation Notes)
- **CSS 渐变与投影**: 使用 `linear-gradient` 和 `box-shadow` 实现。
- **Flex 布局**: 确保卡片在不同机型下都能居中且留白合适。
- **交互逻辑**: 选中心情时触发 `scale` 变换动效。

## 5. 验证标准 (Verification Criteria)
- 页面是否呈现统一的大卡片视觉，而非多个割裂的小方块。
- 心情选中时是否有明显的视觉反馈（缩放与阴影）。
- 整体配色是否和谐，是否体现了“个人日记”的精致感。
