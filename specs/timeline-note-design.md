# Specification: Timeline Note Feature (时间线记录笔记功能)

## 1. 概述
在现有的打卡功能基础上，增加记录笔记、心情、图片和标签的功能。打卡后自动跳转至详情编辑页，并在“我的”页面以时间线形式展示所有记录。

## 2. 用户故事
- 作为用户，我希望在打卡的同时能记录当下的心情和文字笔记。
- 作为用户，我希望能够为打卡记录添加照片。
- 作为用户，我希望能够通过时间线直观地回顾我的生活点滴。

## 3. 验收标准
### 3.1 打卡与流程
- 点击首页“立即打卡”并获取位置成功后，**自动跳转**至“记录详情编辑页”。
- 首页应显示“定位中...”状态，防止重复点击。

### 3.2 记录详情编辑页 (新增)
- **只读信息**：顶部显示自动获取的打卡时间（YYYY-MM-DD HH:mm:ss）和地理位置描述。
- **心情选择**：提供 5 个预设 Emoji（😊, 😢, 💼, 🏖️, 🔥）。
  - **选中效果**：选中项外围显示 **2px 绿色 (#07c160) 正圆形** 边框。
- **文字笔记**：提供多行文本输入框，提示词为“记录这一刻的想法...”。
- **图片上传**：支持从相册选择或拍照。
  - **限制**：最多上传 3 张照片。
  - **展示**：以缩略图形式展示，支持删除。
- **标签系统**：预设标签（#工作, #生活, #旅行），支持输入自定义标签。
- **保存操作**：点击“保存记录”后，更新本地 `PUNCH_RECORDS` 并返回首页或跳转至时间线页。

### 3.3 时间线展示页 (优化“我的”页面)
- **布局设计**：采用标准时间线布局。
  - **左侧**：垂直灰色轴线，每个记录点使用绿色实心圆点（最新一条）或灰色圆点（历史条目）。
  - **右侧**：信息卡片。
- **卡片内容**：
  - 顶部：具体打卡时间。
  - 中部：心情图标（右上角）、笔记内容摘要（最多 2 行）、图片预览（1-3 张缩略图）。
  - 底部：定位图标 + 地点名称，以及标签列表。
- **排序**：严格按时间倒序排列。

## 4. 技术方案
### 4.1 数据结构 (扩展)
`PUNCH_RECORDS` 数组中的每个对象结构：
```typescript
interface PunchRecord {
  id: number;           // 时间戳作为 ID
  time: string;         // 格式化时间
  latitude: string;     // 纬度
  longitude: string;    // 经度
  address: string;      // 地理位置描述 (逆地址解析或 mock)
  mood: string;         // 选中的 Emoji
  note: string;         // 笔记内容
  photos: string[];     // 图片本地临时路径数组
  tags: string[];       // 标签数组
}
```

### 4.2 存储方案
- 使用 `wx.setStorageSync` 和 `wx.getStorageSync` 进行持久化。
- 考虑到图片是本地路径，仅在当前设备有效。

## 5. UI/UX 规范
- **主色调**：微信绿 (#07c160)。
- **背景色**：浅灰色 (#f8f8f8)。
- **字体**：系统默认字体，笔记内容 14px，时间 12px。
- **圆角**：卡片圆角 12px，心情选中圆角 50%。

## 6. 验证计划
1.  **打卡跳转**：验证打卡成功后是否立即进入编辑页。
2.  **心情选中**：验证心情图标选中时边框是否为正圆形。
3.  **多图上传**：验证超过 3 张图片时的限制逻辑。
4.  **时间线渲染**：验证“我的”页面是否能正确展示不同类型的记录卡片。
